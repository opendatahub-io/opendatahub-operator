## Objective

Verify the current interim v3 carry-over and identity conversion for the
deprecated Training Operator and Llama Stack Operator stanzas:

- `spec.components.trainingoperator` remains `DSCTrainingOperator` and its
  status remains `DSCTrainingOperatorStatus`.
- `spec.components.llamastackoperator` remains `DSCLlamaStackOperator` and its
  status remains `DSCLlamaStackOperatorStatus`.
- JSON names, optionality, defaults, deprecation comments, status fields,
  conditions, and validation remain unchanged from v2.
- `ogx` and `trainer` remain separate components; do not rename either legacy
  stanza to those newer components.

The current repository carries these fields in `api/datasciencecluster/v3` as
part of the initial v2-shaped API. Verify generated artifacts and conversion
coverage without changing Go types. This task does not approve final retention
and is not permission to alter component handlers, lifecycle semantics,
warnings, CEL rules, or runtime reconciliation.

## Required conversion contract

For both stanzas, implement or explicitly confirm direct copying in both
directions through the v3 hub:

| Input | Output | Required behavior |
| --- | --- | --- |
| v2 spec `components.trainingoperator` | v3 spec `components.trainingoperator` | Direct copy for absent, empty, and non-empty values |
| v3 spec `components.trainingoperator` | v2 spec `components.trainingoperator` | Direct copy; no annotation or normalization |
| v2 status `components.trainingoperator` | v3 status `components.trainingoperator` | Direct copy, including status and conditions |
| v3 status `components.trainingoperator` | v2 status `components.trainingoperator` | Direct copy, including status and conditions |
| v2 spec/status `components.llamastackoperator` | v3 same-named spec/status | Direct copy for absent, empty, and non-empty values |
| v3 spec/status `components.llamastackoperator` | v2 same-named spec/status | Direct copy; no annotation or normalization |

Do not add a fidelity marker. Do not drop non-empty values. Preserve the
existing Training Operator re-enablement CEL validation and the existing
deprecation guidance. Conversion must not call admission, perform lookups, or
change management state.
