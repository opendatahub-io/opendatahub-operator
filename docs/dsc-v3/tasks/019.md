# DSC-V3-019: complete conversion protocol and API-server coverage

## Objective

Prove the real DSC `/convert` protocol and API-server v2 read-modify-write
behavior for every migrated component. Direct ConversionReview requests belong
in integration tests, not cluster E2E tests.

## Required scenarios

- POST `apiextensions.k8s.io/v1` ConversionReview to `/convert` in both desired
  directions, singly and with multiple DSC objects. Assert response UID,
  object order/count, desired apiVersion, spec/status transformations, and
  malformed/unsupported-request failure behavior.
- Through envtest API-server GET/UPDATE, cover Dashboard, AIHub, Data,
  canonical/legacy MaaS, and retired fields. Include status-subresource writes,
  conditions, unrelated fields, and v3-only data preservation where the
  accepted conversion contract permits it. Do not synthesize or rename
  component release entries: modules populate the deployed-component status,
  and the v2/v3 converter passes release entries through unchanged.
- Apply DEC-024 MaaS normalization and marker retirement, not blanket exact
  round-trip preservation.

## Verification

Run focused integration tests, mandatory Make gates, and `git diff --check`.

## Outcomes

Implemented direct `apiextensions.k8s.io/v1` ConversionReview HTTP tests for
single- and multi-object v2↔v3 requests, order, UID, migrated fields,
retirement projection, unsupported versions, and malformed JSON. Expanded
the envtest v2 client flow to cover Dashboard, AIHub, Data, canonical MaaS,
conditions, retired states, and unrelated updates. A v2 status subresource
write verifies AIHub management state and condition conversion through v3
storage without inventing module-owned release entries. Existing
`conversion/maas` integration cases cover legacy MaaS normalization and marker
retirement. Direct `/convert` requests remain integration-only.

Focused envtest tests pass with the repository's Kubernetes 1.36.2 binaries;
`make generate manifests`, `make fmt`, and `make lint` pass. A full
`make unit-test` run stalled in an unrelated DataSciencePipelines test and was
stopped; its result remains unverified. `make api-docs` is deferred because
`docs/api-overview.md` has pre-existing user changes.
