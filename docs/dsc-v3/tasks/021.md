# DSC-V3-021: expand retired-operator conversion E2E

## Objective

Extend the existing DSC conversion webhook E2E branches for TrainingOperator
and LlamaStackOperator. These are fresh-install retirement tests, not evidence
of an old installed operator being upgraded.

## Required scenarios

- Create v2 DSCs with explicit `Removed`, omitted, and empty legacy state;
  verify v3 spec/status omission and v2 spec/status `Removed` on readback.
- Reject new v2 `Managed` requests and `Removed`-to-`Managed` updates. An
  unrelated v2 update must succeed while both states remain `Removed`.
- Remove unrelated replacement-component enablement from the fixtures.
- Reuse the conversion suite's DSCI setup and DSC cleanup; do not assert
  cleanup by legacy operators absent from 3.6.

## Verification

Run focused local tests and E2E compilation, mandatory Make gates, and
`git diff --check`; record the exact installed-image cluster job for final
qualification if unavailable locally.

## Outcomes

Implemented shared fresh-install scenarios for both retired operators:
explicit `Removed`, empty component stanza (`{}`), omitted component,
v3-to-v2 projection, rejected new `Managed`, rejected re-enable, and an
unrelated v2 update. In every accepted case, the v3 spec/status omits the
retired fields and v2 spec/status reads `Removed`. Removed OGX/Trainer
enablement from the fixtures. A literal `managementState: ""` is disallowed by
the v2 CRD enum; an empty stanza tests the accepted empty-state API case.

The no-cluster fixture test and top-level E2E package compilation pass.
`make generate manifests`, `make fmt`, `make lint` (0 issues), and
`git diff --check` pass. Installed-image cluster qualification is pending;
run `TestOdhOperator/webhooks/conversion/dsc/(trainingoperator|llamastackoperator)`
with the final image. `make api-docs` is deferred because
`docs/api-overview.md` contains pre-existing user changes.
